# Portfolio

個人ポートフォリオサイト

## Tech Stack

- Next.js 15 / React 19 / TypeScript
- Tailwind CSS 4
- ESLint + Prettier + husky

## Getting Started

```bash
npm install
npm run dev
```

http://localhost:3000 で確認できます。

## Scripts

| コマンド         | 説明                   |
| ---------------- | ---------------------- |
| `npm run dev`    | 開発サーバー起動       |
| `npm run build`  | 本番ビルド             |
| `npm run lint`   | ESLint実行             |
| `npm run format` | Prettierでフォーマット |

## Deploy

mainブランチにプッシュすると、GitHub Actionsで自動的にGitHub Pagesへデプロイされます。
